# קו AI סוכנותי רב-שלבי לימות המשיח (גרסה 3.0)

שרת Node.js מתקדם המחבר סוכן בינה מלאכותית קולי רב-שלבי (מבוסס Gemini) למערכת הטלפוניה של **ימות המשיח**, עם ניווט תחבורה ציבורית טבעי ומדויק בישראל, חיפוש מקומות ושעות פתיחה, מחקר רשת מקבילי, חדשות ורדיו RSS, יצירת תמונות ואודיו ושליחת סיכומים למייל, וזיכרון מתקשר קבוע בשלוחת ההיסטוריה.

---

## יכולות המערכת המרכזיות

1. **לולאת סוכן רב-שלבית (Multi-Step Agent עד 6 שלבים):**
   - הסוכן מתכנן ומחבר כלים בשרשרת בתוך אותה שאלה — למשל: איתור כתובת ושעות פתיחה של מוסד או עסק (`google_places_search`), חישוב מסלול תחבורה ציבורית אליו (`google_maps_route`), ושליחת הסיכום המלא למייל (`send_email`).
   - בזמן העבודה המתקשר שומע דיווחי ביניים חיים על כל שלב מתבצע, ויכול להקיש `0` לביטול משימה ארוכה.
   - שמירת **זיכרון עבודה תוך-שיחתי** (`workingMemory`) וזיהוי קטיעת תשובה באמצע (Barge-in), כך ששאלות המשך נענות מיד עם כל הנתונים מהתור הקודם.

2. **ניווט ותחבורה ציבורית בעברית טבעית (`google_maps_route`):**
   - מבוסס על **Google Routes API v2** עם תיקון עצמי אוטומטי: אם כתובת עמומה — המערכת מאתרת אוטומטית את ה-Place ID המדויק דרך Google Places; אם מדובר בשעת לילה שבה אין קווים פעילים — המערכת בודקת אוטומטית את הקווים הראשונים בבוקר הקרוב.
   - תמיכה מלאה בשעון ישראל (`Asia/Jerusalem`), כולל בקשות לפי **שעת יציאה** או **שעת הגעה מבוקשת** ("איך להגיע עד 09:00 מחר?").
   - **ניסוח קולי טבעי ומוקפד:** איחוד מקטעי מיקרו-הליכה למשפט רהוט אחד, פתיחת ראשי תיבות של משרד התחבורה (`ת. מרכזית` -> `תחנה מרכזית`, `שד'` -> `שדרות`, `רח'` -> `רחוב`, לוכסן תחנות -> `פינת`), זיהוי סוג כלי הרכב (אוטובוס, רכבת ישראל, הרכבת הקלה, רכבלית/כרמלית), וחישוב זמני המתנה בהחלפות ושעת הגעה סופית ליעד.
   - **תצוגת ברירת מחדל:** פירוט מלא צעד-אחר-צעד של **החלופה המהירה ביותר** מיד, בתוספת תקציר קצר וברור של חלופות 2 ו-3 ותפריט מקשים עשיר:
     - `1` / `2` / `3` — שמיעת פירוט מלא של חלופה 1, 2 או 3
     - `4` — שליחת כל המסלולים והתחנות כתדפיס מסודר למייל
     - `5` — שמיעת הוראות הליכה מפורטות רחוב-אחר-רחוב
     - `8` — בדיקת אוטובוסים מאוחרים יותר (בעוד 30 דקות)
     - `9` — שמיעה חוזרת של הסקירה המלאה
     - `0` — מעבר לשאלת המשך או לבקשה חדשה

3. **כלים סוכנותיים משולבים:**
   - `google_places_search` — כתובות מדויקות, מספרי טלפון, סטטוס פתוח/סגור ושעות פתיחה של עסקים ומוסדות בישראל.
   - `web_search_parallel` + `fetch_webpage` — חיפוש מקבילי של 3–8 שאילתות ב-Groq וקריאת עמודי אינטרנט מלאים לעומק.
   - `play_rss_radio` — השמעת מהדורות חדשות מוקלטות ופודקאסטים מ-RSS (בהמרת `ffmpeg`), הקראת מבזק כותרות חי מפידים טקסטואליים (כמו קול חי ו-JDN), או העברה לשלוחת שידור חי (`LIVE_STREAM_EXT`).
   - `send_email` — שליחת סיכומי מחקר, מסלולי הגעה, רשימות ומידע למייל המוגדר דרך Google Apps Script.
   - `generate_image` — יצירת 1–4 תמונות חדשות בבינה מלאכותית ביחס גובה-רוחב מותאם ושליחתן למייל.
   - `search_and_email_images` — חיפוש תמונות אמיתיות קיימות בגוגל תמונות (עד 20 מ"ב) ושליחתן למייל.
   - `generate_audio` — יצירת קריינות מותאמת אישית להשמעה בקו, לשליחה למייל או לשניהם.
   - `save_caller_memory` — שמירת פרטים קבועים למתקשר (כגון כתובת בית/עבודה לניווט מהיר או שם) הנשמרים בין שיחות.

4. **זיכרון מתקשר קבוע ושלוחת היסטוריה (`HISTORY_EXT=9`):**
   - פרופיל המתקשר, העדפות הקול/הקצב ושיחות העבר נשמרים כקובץ JSON מוצפן-גישה בתיקיית השלוחה בימות המשיח (`ivr2:/9/mem_<phone>.ini`), כך שהמידע נשמר לתמיד גם לאחר אתחול או מצב שינה ב-Render Free.
   - בכניסה לשלוחה `9` (בין אם מוגדרת ל-`/history` ובין אם ל-`/yemot`), נפתח תפריט ההיסטוריה:
     - `1` — השמעת השיחה המלאה
     - `2` — המשך השיחה מאותה נקודה עם כל ההקשר השמור
     - `3` — מחיקת השיחה (`1` לאישור)
     - `4` — שליחת תמליל השיחה למייל
     - `5` / `6` — מעבר לשיחה הבאה / הקודמת
     - `0` — חזרה לתפריט הראשי

## הגדרת השלוחות בימות המשיח

- **שלוחה `1` (`EXT_PATH`):** שלוחה רגילה (`type=playfile`) לאחסון זמני של הקלטות ומקטעי השמעה.
- **שלוחה `5` (שלוחת הסוכן הראשית):** בקובץ `ext.ini`:
  ```ini
  type=api
  api_link=https://<השירות-שלך>.onrender.com/yemot
  ```
- **שלוחה `7` (`LIVE_STREAM_EXT`, אופציונלי):** שלוחת שידור חי (`type=online_radio`).
- **שלוחה `9` (`HISTORY_EXT`, היסטוריה וזיכרון):** בקובץ `ext.ini`:
  ```ini
  type=api
  api_link=https://<השירות-שלך>.onrender.com/history
  ```
  *(השרת מזהה אוטומטית את שלוחה 9 גם אם `api_link` שלה מצביע ל-`/yemot`).*

## הקלדה במקשי הטלפון (שלוחה -> מקש 2)

| מקש | הקשה 1 | הקשה 2 | הקשה 3 | הקשה 4 | הקשה 5 |
|---|---|---|---|---|---|
| `3` | א | ב | ג | — | 3 |
| `2` | ד | ה | ו | — | 2 |
| `6` | ז | ח | ט | — | 6 |
| `5` | י | כ | ך | ל | 5 |
| `4` | מ | ם | נ | ן | 4 |
| `9` | ס | ע | פ | ף | 9 |
| `8` | צ | ץ | ק | — | 8 |
| `7` | ר | ש | ת | — | 7 |

- `0` — רווח | `00` — מחיקת תו אחרון | `1` — הפרדה בין שתי אותיות על אותו מקש | `11` — הספרה 1 | `#` — סיום ושליחה.
- אותיות סופיות (`ך ם ן ף ץ`) מומרות אוטומטית גם בסוף מילה.

## משתני סביבה ב-Render

| משתנה | תיאור |
|---|---|
| `GEMINI_API_KEYS` | מפתח אחד או יותר (מופרדים בפסיק) ל-Gemini API |
| `GEMINI_TTS_KEYS` | מפתחות ל-Gemini TTS (אם ריק, משתמש ב-`GEMINI_API_KEYS`) |
| `GROQ_API_KEYS` | מפתחות ל-Groq API לחיפוש מקבילי ברשת |
| `GOOGLE_MAPS_API_KEY` | מפתח Google Cloud עם הרשאות ל-Routes API ול-Places API (New) |
| `GOOGLE_SEARCH_CX` | מזהה מנוע חיפוש מותאם (Programmable Search Engine) לחיפוש תמונות בגוגל |
| `YEMOT_TOKEN` | טוקן API של הקו בימות המשיח |
| `TEXT_MODEL` | מודל ראשי לסוכן (מומלץ: `gemini-3.6-flash`) |
| `TEXT_MODEL_FALLBACK` | שרשרת גיבוי מופרדת בפסיקים (למשל: `gemini-3.5-flash-lite,gemini-3.1-flash-lite`) |
| `TTS_MODEL` | שרשרת מודלי הקראה (`gemini-3.8-flash-tts,gemini-3.8-flash-lite-tts,gemini-3.1-flash-tts-preview,gemini-2.5-flash-preview-tts`) |
| `IMAGE_MODEL` | מודל יצירת תמונות (`gemini-3.1-flash-lite-image` או `imagen-3.0-generate-002`) |
| `GAS_MAIL_URL` | כתובת ה-Web App (`/macros/s/.../exec`) של Google Apps Script לשליחת מיילים |
| `GAS_MAIL_SECRET` | טוקן האימות מול סקריפט המייל |
| `TARGET_EMAIL` | כתובת המייל של בעל הקו לקבלת מסלולים, סיכומים ותמונות |
| `RADIO_FEEDS` | מערך JSON של תחנות/פידים (`[{"n":"חדשות כאן","u":"..."}]`) |
| `EXT_PATH` | שלוחת ברירת מחדל לקבצי שמע (`1`) |
| `LIVE_STREAM_EXT` | מספר שלוחת השידור החי (`7`) |
| `HISTORY_EXT` | מספר שלוחת ההיסטוריה והזיכרון (`9`) |
| `MAX_WORDS` | אורך תשובה מרבי במילים (`1200`) |

## נתיבי השרת

| נתיב | תפקיד |
|---|---|
| `GET /` | בדיקת חיים מהירה (`ok`) |
| `ALL /yemot` | נתיב השיחה הראשי לימות המשיח (תומך גם ב-`/yemot/:ext`) |
| `ALL /history` | נתיב שלוחת ההיסטוריה וניהול שיחות שמורות |
| `GET /selftest` | בדיקת תקינות חיה ומקיפה (JSON) לכל המפתחות, המודלים, המפות, ימות המשיח והרדיו |
